SMITH'S CLASSROOM — art files
=============================
Put this whole "assets" folder in the same place as smiths-classroom.html.
The app picks these up automatically. No code changes.

  title.png        Title screen background. NOT INCLUDED — save your
                   "Smith's World" title image as assets/title.png.
  smith_idle.png   Coach Smith standing (title screen + home screen)
  smith_cheer.png  Celebrating (correct answers + certificate)
  smith_hmm.png    Reacting (wrong answers)
  runner.png       Player sprite in Circuit Runner
  kart.png         Player sprite in Fare Rush
  smith_point.png  Spare pose, not wired up yet
  smith_walk.png   Spare pose, not wired up yet

These were cut from your own sheets and the checkerboard was removed,
so each one is a real transparent PNG. To swap any of them, either
replace the file here or use Teacher > Classroom art inside the app.
